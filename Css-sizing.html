CSS Units Practice

px, %, em, rem Boxes

100px width & 50px height
50% width → 200px
2em height → 40px
2rem height → 32px

Quick Rules / Use Cases

  • px: Fixed design elements, icons, borders, small components.
  • %: Responsive layouts, widths, heights, flexible containers.
  • em: Component-based spacing, typography relative to parent.
  • rem: Global spacing, consistent font sizes, scalable typography.
